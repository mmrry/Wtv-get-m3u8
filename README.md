# W.tv — master m3u8 записей

Userscript для Tampermonkey. Добавляет на превью каждой записи стримера на [w.tv](https://w.tv) кнопку **`m3u8`**, которая копирует в буфер обмена ссылку на `master.m3u8` этой записи.

Пример страницы: `https://w.tv/<user>/videos`

## Возможности

- Кнопка `m3u8` в правом верхнем углу превью каждой записи.
- Копирует ссылку на **master**-плейлист со всеми качествами, а не на поток одного качества.
- Клик по кнопке не открывает запись.
- Кнопки появляются и у записей, которые подгружаются при прокрутке, и после переходов по сайту без перезагрузки.
- Каждая ссылка проверяется в фоне. Если это не master или плейлист недоступен, текст кнопки становится жёлтым, а при наведении появляется подсказка с причиной.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для своего браузера.
2. Откройте панель Tampermonkey и выберите **«Создать новый скрипт»**.
3. Удалите шаблон, вставьте содержимое файла `wtv-master-m3u8.user.js` и сохраните (`Ctrl+S`).
4. Откройте страницу записей стримера, например `https://w.tv/<user>/videos`.

**Обновление:** замените код скрипта в Tampermonkey новой версией файла и перезагрузите страницу.

## Использование

1. Откройте страницу записей стримера (`https://w.tv/<стример>/videos`).
2. Нажмите **`m3u8`** на превью нужной записи. На секунду появится надпись «Скопировано».
3. Откройте ссылку в плеере или загрузчике, например:

   ```bash
   # просмотр
   mpv "https://…/media/hls/master.m3u8"

   # скачивание в лучшем качестве
   yt-dlp "https://…/media/hls/master.m3u8"

   # скачивание без перекодирования
   ffmpeg -i "https://…/media/hls/master.m3u8" -c copy record.mp4
   ```

VLC тоже открывает такие ссылки: «Медиа» → «Открыть URL».

## Как это работает

W.tv хранит записи эфиров на Amazon IVS. Каждая запись лежит в отдельной папке со стандартной структурой:

```text
<prefix>/media/hls/master.m3u8                 ← master-плейлист (все качества)
<prefix>/media/hls/<качество>/playlist.m3u8    ← плейлист одного качества
<prefix>/media/thumbnails/thumbN.jpg           ← превью
```

Скрипт берёт адреса записей из трёх источников:

1. **Превью карточек.** По адресу картинки `…/media/thumbnails/…` скрипт находит папку записи и составляет ссылку `…/media/hls/master.m3u8`.
2. **Ответы API сайта.** Скрипт отслеживает ответы `fetch` и `XMLHttpRequest` и забирает из JSON ссылки на `.m3u8` вместе с id записи.
3. **Плеер.** Если открыта запись, скрипт видит, какие плейлисты загружает плеер. Ссылку на плейлист одного качества он заменяет на `master.m3u8`.

Чтобы проверить ссылку, скрипт скачивает плейлист и ищет в нём строку `#EXT-X-STREAM-INF`: она есть только в master-плейлисте.

## Значения кнопки

| Вид кнопки | Значение |
|---|---|
| Белый текст `m3u8` | master-плейлист подтверждён, или проверка ещё идёт или невозможна |
| Жёлтый текст `m3u8` | плейлист одного качества или плейлист недоступен (причина в подсказке) |
| «Скопировано» | ссылка в буфере обмена |
| «Ошибка» | буфер обмена недоступен; ссылка показана в окне, её можно скопировать вручную |

## Ограничения

- Если W.tv отдаёт превью не из хранилища записей, а со своего сервера, кнопки на карточках не будет. Тогда ссылка находится через API или после открытия записи.
- Скрипт рассчитан на текущую структуру сайта и хранилища IVS. Если W.tv её поменяет, скрипт придётся обновить.
- Скрипт ничего не скачивает и никуда не отправляет. Он только читает данные, которые сайт и так загружает в браузер.

## Совместимость

- Tampermonkey в Chrome, Edge, Firefox и других браузерах на Chromium.
- Violentmonkey тоже должен работать: разрешения `GM_*` скрипт не использует (`@grant none`).
